Интенсив 4: Классификация позитивных комментариев по работе
управляющей компании

📚Описание проекта

Этот репозиторий содержит решение кейса "Классификация позитивных комментариев по работе
управляющей компании", разработанного в рамках Интенсива 4. Цель проекта — разработать модель машинного или глубокого обучения, позволяющая на основе имеющихся данных проводить классификацию комментариев по нужным категориям.

📊Что делает наша модель?

▪️ Анализирует комментарии

▪️ Использует алгоритмы машинного обучения для классификации комментариев


📂 Структура репозитория

main.ipynb – применение модели

data.csv – размеченные комментарии

README.md – текущее описание


🔧 Используемые технологии

Python, Jupyter Notebook

Pandas, Scikit-learn

DeepPavlov/rubert-base-cased, cointegrated/rubert-tiny2, sberbank-ai/ruBert-large

Google Colab (для обучения и тестирования)
